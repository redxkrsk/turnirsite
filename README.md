# REDX ARENA

Адаптивный лендинг турнира CS2 / Dota 2: HTML5, Tailwind CSS через CDN, самостоятельные CSS-стили, Vanilla JavaScript, Google Fonts, Font Awesome. Сборка и npm-зависимости не требуются.

## Запуск

```sh
cd /workspace/turnirsite
python -m http.server 8000 --bind 0.0.0.0
```

Для публикации разместите содержимое каталога на любом статическом HTTPS-хостинге. Рабочий сервер для заявок нужен отдельно.

## Настройка

В `config.js` указаны дата 24 октября 2026 и предполагаемое время 12:00 по Красноярску (UTC+7). Регистрация закрывается 23 октября в 23:59:59. Время требует подтверждения организатора. Призы, число команд и расписание демонстрационные. Тексты о призах находятся в `index.html`, расписание — в `app.js`.

- `registrationEndpoint`: HTTPS API, принимающий JSON POST. Нужны серверная валидация, защита от повторных заявок и спама, допустимый CORS origin, политика обработки персональных данных. Успешный HTTP-ответ означает приём заявки, а не подтверждение участия. Без API работает честно обозначенный деморежим localStorage. Демоданные удаляются через «условия участия».
- `discordServerId`: настоящий ID сервера с включённым Server Widget. Без ID виджет не загружается.
- `discordInvite`: действующая HTTPS-ссылка приглашения Discord.
- `partnerEmail`: реальный адрес организатора для партнёров.

Не добавляйте секреты в config.js: это публичный файл. Перед реальным сбором заявок замените демоусловия в разделе FAQ и диалоге регламента на утверждённые правила и политику обработки данных. Социальные ссылки ведут на общие сервисы, замените их каналами турнира.

## Изображения и шрифты

Реальные фотографии Unsplash используются по прямым URL; при сетевой ошибке загружаются локальные копии этих же фото:

- https://images.unsplash.com/photo-1542751371-adc38448a05e
- https://images.unsplash.com/photo-1511512578047-dfb367046420

Прямые URL images.unsplash.com проверены: HTTP 200, image/jpeg. Локальные файлы: assets/arena.jpg и assets/gaming.jpg. SVG-знак вручную воспроизводит красный символ предоставленного логотипа; это не исходный файл вложения.

Font Awesome 6.7.2 сохранён локально из cdnjs вместе с WOFF2 для надёжного отображения иконок. Лицензия: https://fontawesome.com/license/free (иконки CC BY 4.0, шрифты SIL OFL 1.1, код MIT). Google Fonts: Inter и Orbitron; при отсутствии сети используется системный шрифт. Tailwind подключён CDN согласно заданию; самостоятельные стили обеспечивают отображение без CDN.

## Проверено

Браузер Chromium: десктоп и мобильная ширина 390 px; переключение расписания и дисциплин; ошибки обязательных полей; сохранение демозаявки и подтверждение; безопасный вывод введённого текста; удаление локальных данных; мобильное меню; отсутствие горизонтального переполнения и ошибок JavaScript. Реальная отправка API и Discord не проверены: адрес API и ID сервера не предоставлены.

## Скачать и открыть

На GitHub выберите **Code → Download ZIP**, распакуйте архив и откройте `REDX-ARENA.html` двойным щелчком. В этом файле встроены стили, фотографии, иконки и JavaScript; он подходит для просмотра без установки инструментов. Для разработки используйте исходные index.html, styles.css, app.js и config.js. Самостоятельный HTML — экспорт; после изменения исходников его нужно пересобрать.
